# Lightfolio 开发记录

## 项目定位

Lightfolio 是一个面向个人摄影作品管理与浏览的本地电子相册应用。
当前技术栈为 Electron + React + TypeScript，采用 monorepo 结构拆分为 app、core、shared 三层。

## 当前已完成

### 工程与构建

- 完成 workspace 架构整理，根目录可统一执行 typecheck 与 build。
- 修复 core/shared 在 ESM 运行时的导出路径问题。
- 修复 app 的 Electron 入口路径与 preload 入口路径。
- 已形成 app、core、shared 三层职责分离：renderer 负责界面交互，core 负责索引与元数据处理，shared 负责跨包类型。
- 当前主线功能改动均已通过根目录 typecheck 校验。

### 导入链路

- 已支持选择单张或多张图片/视频文件导入。
- 已支持选择目录后递归扫描图片/视频文件。
- 已加入导入去重逻辑，避免同一文件重复进入时间轴。
- 已支持基于目录的持续浏览与重新导入，适配“本地文件夹即相册来源”的使用方式。

### 元数据

- 已接入 EXIF 读取基础能力。
- 拍摄时间采用回退策略：EXIF 时间 -> 文件修改时间 -> 导入时间。
- 已支持展示并解析更完整的拍摄信息，包括相机、镜头、光圈、快门、ISO。
- 已支持标题、说明、标签、精选状态的编辑，并在编辑后回写到本地快照。
- 已区分“收藏”与“精选”语义：收藏偏个人偏好，精选用于故事流与展示编排。

### 界面与交互

- 已形成更稳定的桌面式三栏布局：左侧导航、中间主视图、右侧详情面板，底部为横向胶卷栏。
- 左右侧栏的上下边界已对齐，整体结构更接近传统看图工具。
- 已支持从相册移除资源，不删除磁盘原文件。
- 已支持将磁盘文件移动到系统回收站。
- 已支持搜索、媒体类型筛选、仅收藏、仅精选、标签筛选、相机筛选、镜头筛选。
- 已支持收藏切换、精选切换、常用标签展示与筛选清空。
- 已支持详情面板内编辑标题、说明、标签，并提供更清晰的文件信息与 EXIF 展示。
- 主图已支持双击放大到 100%、再次双击恢复适配视图、Ctrl + 滚轮连续缩放、拖拽平移查看细节。
- 已加入常规缩放控件，包括缩放比例显示、按钮与滑杆。
- 已支持主图区域全屏查看，并加入 F / F11 快捷键。
- Toast 提示已支持自动消失，减少界面停留干扰。

## 当前已知问题

- 主图缩放与全屏交互已经可用，但仍需要继续观察极端尺寸图片下的边界手感与残余抖动。
- 当前标题默认仍以文件名兜底，后续若接入 AI 命名或更完整的内容策展，需要补充标题生成与人工覆盖策略。
- 从相册移除后的批量恢复入口已移除；当前策略更偏向保持界面简洁，如需恢复，重新导入目录即可。
- Windows 下运行时存在 cache 目录权限告警，但当前不阻塞主功能。

## 设计原则

- 不移动、不复制、不隐式修改用户磁盘中的原始素材。
- “从相册移除”仅影响 Lightfolio 内部视图，不影响原文件。
- 当前默认不提供常驻“恢复已移除”入口，优先保持界面简洁；需要重新纳入时，可重新导入原目录。
- “删除磁盘文件”必须是显式危险操作，并走系统回收站。
- 数据层优先保存索引、标签、说明、隐藏状态等元信息，而不是保存素材本体。
